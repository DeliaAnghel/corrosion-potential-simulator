Electrozi și potențialul de coroziune

Electrodul este un sistem electroneutru format dintr-un metal și soluția de electrolit. În medii corozive, reacțiile la interfața metal/soluție sunt ireversibile, generând spontan o diferență de potențial – potențialul de coroziune (εcor).

Se defineşte drept electrod sistemul electroneutru metal /soluţie de electrolit. Electrozii pot fi reversibili şi ireversibili. Electrozii reversibili sunt caracterizaţi de reacţii de echilibru la interfaţa metal/soluţie de electrolit. Când soluţia reprezintă un mediu coroziv, reacţiile la interfaţa metal/soluţie de electrolit sunt ireversibile. Ca urmare a desfăşurării simultane a proceselor de ionizare a metalului (procese anodice) şi a depolarizării, a reducerii agenţilor corozivi din soluţia de electrolit (procese catodice) pe aceeaşi suprafaţă metalică, la interfaţa metal/mediu coroziv apare spontan o diferenţă de potenţial, numită potenţial de coroziune. Procesul global al coroziunii cu depolarizare de hidrogen/oxigen se obţine prin însumarea algebrică a reacţiilor de ionizare a metalului (oxidare) şi a reacţiei de depolarizare (reducere) a ionilor sau a moleculelor din mediul coroziv.

Reacții chimice

1. Coroziune cu depolarizare de hidrogen

În medii acide: 
Oxidare:        Fe → Fe²⁺ + 2e⁻
Reducere:       2H⁺ + 2e⁻ → H₂
Reacție globală: Fe + 2H⁺ → Fe²⁺ + H₂
În medii neutre și alcaline: 
Oxidare:        Fe → Fe²⁺ + 2e⁻
Reducere:       2H₂O + 2e⁻ → 2OH⁻ + H₂
Reacție globală: Fe + 2H₂O → Fe²⁺ + 2OH⁻ + H₂

2. Coroziune cu depolarizare de oxigen

În medii acide: 
Oxidare:        Fe → Fe²⁺ + 2e⁻
Reducere:       2H⁺ + ½O₂ + 2e⁻ → H₂O
Reacție globală: Fe + 2H⁺ + ½O₂ → Fe²⁺ + H₂O
În medii neutre și alcaline: 
Oxidare:        Fe → Fe²⁺ + 2e⁻
Reducere:       H₂O + ½O₂ + 2e⁻ → 2OH⁻
Reacție globală: Fe + H₂O + ½O₂ → Fe(OH)₂

Formula potențialului de coroziune și a supratensiunii

Potenţialul de coroziune şi supratensiunea depind de natura chimică şi starea suprafeţei metalului, de natura chimică şi pH-ul mediului coroziv.

εcor = Emăsurat + 0.266 V

ηa = εcor - ε01 (supratensiune anodică, unde ε01 este potențialul standard al metalului)

ηc = εcor - ε02 (supratensiune catodică, unde ε02 este potențialul agentului oxidant din soluție)

Aparatură și substanțe

Aparatură: instrument de măsură, cuve cu soluții, electrozi de fier, zinc, aluminiu.

Substanțe: soluții de acid sulfuric, hidroxid de sodiu și clorură de sodiu.

Modul de lucru

  • Se curăță plăcuțele metalice (electrozii) cu hârtie metalografică înaintea fiecărei măsurători.
  • Se alcătuiesc pile galvanice, în care un electrod este metalul introdus în mediul coroziv, iar celălalt este electrodul de referință:
(-) M / H₂SO₄ // electrod de referință (+)
(-) M / NaOH  // electrod de referință (+)
(-) M / NaCl  // electrod de referință (+)

Ca electrod de referință se poate folosi electrodul de Ag/AgCl, cu ε0Ag⁺/AgC = +0.266 V.

Electrodul de referință se conectează la bornele voltmetrului și se notează valoarea t.e.m. indicată de afișajul electronic după două minute, când se consideră că a atins o valoare relativ constantă.

Valori standard ale potențialelor

Sistem ε⁰ (V)
Fe²⁺ / Fe -0.44
Zn²⁺ / Zn -0.763
Al³⁺ / Al -1.66
Mg²⁺ / Mg -2.37
Sn²⁺ / Sn -0.14
Ni²⁺ / Ni -0.25
H⁺ / H₂ (acid) 0.00
O₂ / OH⁻ (neutru/alcalin) +0.401
Ag/AgCl (referință) +0.266
